# 📌 Team Task Manager (Full-Stack Web App)

A full-stack web application that allows teams to manage projects, assign tasks, and track progress with **role-based access control (Admin / Member)**.

## 🎯 Features

### 🔐 Authentication
- User Signup & Login
- Session-based authentication
- Role-based access (Admin / Member)

### 📁 Project Management
- Admin can create projects
- Projects linked with tasks

### ✅ Task Management
- Create tasks with title, description, deadline
- Assign tasks to users
- Update task status:
  - Pending → In Progress → Done

### 📊 Dashboard
- View all tasks
- Task statistics:
  - Total tasks
  - Completed tasks
  - Pending tasks
  - Overdue tasks
